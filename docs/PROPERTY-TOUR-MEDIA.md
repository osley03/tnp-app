# Property photos and 360 tours

Primary listing photos are previewed in the property form, landlord property drawer, landlord tour library, and alongside the internal or external tour. Native tours load the linked listing using the signed-in user and existing Supabase permissions. The property parameter preserves the listing context without putting an image URL into the tour link. Photos do not replace room panoramas.

Tour player, editor, library, gallery and legacy viewer provide a return link to the actual signed-in role dashboard. Embed mode hides dashboard controls and listing photos. Broken or missing image URLs show a labelled placeholder. Account deletion uses the standard icon sidebar menu and retains the existing confirmation workflow.
